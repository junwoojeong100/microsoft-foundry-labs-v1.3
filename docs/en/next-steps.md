# Before using this at work

**English** | [한국어](../next-steps.md) · [Course home](../../README.md)

Completing the self-paced lab does not grant production approval. Use the application card in your [private workbook](../../worksheets/en/workbook.md) to define:

1. The actual problem and business metrics to measure.
2. Approved source data, access permissions, and update ownership.
3. Separation of read-only tools from real write/approval tools.
4. Evaluation data, error handling, business boundaries, and regression gates.
5. User authentication, managed identities, networking, and sensitive-log minimization.
6. Cost, incident, rollback, and deletion responsibilities.

Start with one small task and a limited user group, repeatedly checking sources, execution, and quality. Adding more models or agents alone does not solve operational problems.
