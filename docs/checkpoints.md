## 명령과 자리표시자 읽기

| 표시 | 할 일 |
|---|---|
| `python ...`, `az ...`, `azd ...` | README가 있는 폴더의 터미널에서 실행 |
| 코드 상자의 `bash` / `powershell` | 언어 표시. 이 단어는 입력하지 않음 |
| `실제-...`, `YOUR-...`, `ACTUAL-...`, `<...>` | 앞 단계에서 확인한 **내 값**으로 변경. 따옴표는 남기고 꺾쇠는 제거 |
| `--label baseline` | 결과 묶음 이름. 바꾸면 후속 평가·비교 명령도 같은 이름 사용 |
| `--output outputs/...json` | 새 결과 파일 경로. 실행 후 편집기에서 열기 |
| JSON·YAML·질문·출력 예시 | 명령 아님. 지정한 편집기·Playground에서 사용 |
| `선택` / `대신` / 접힌 절 | 해당 조건일 때만 사용. 기본 명령에 전부 추가하지 않음 |

### 명령 하나를 실행하는 순서

1. 상자 위에서 **실행 위치와 바꿀 값**을 확인합니다.
2. 상자 전체를 복사해 실행합니다.
3. 프롬프트가 돌아오면 아래 **확인**과 결과를 대조합니다.

긴 명령도 한 줄 전체를 복사합니다. 화면의 자동 줄바꿈은 괜찮지만 Enter·`\`·PowerShell 백틱으로 직접 나누지 않습니다.

서버를 실행하는 `serve`만 프롬프트가 돌아오지 않는 것이 정상입니다. [터미널 A/B 안내](#두-터미널을-사용하는-장)를 따릅니다.

> [!WARNING]
> `--confirm-create`, `--confirm-cost`, `--confirm-delete`는 생성·과금·삭제 동의입니다. **이 옵션이 없는 모델 호출도 유료일 수 있습니다.** 실행할 대상과 비용을 먼저 확인합니다.

## 결과 파일을 읽고 다음 명령에 값 옮기기

편집기의 파일 탐색기에서 출력된 경로를 엽니다. **파일 생성 자체는 성공 증거가 아닙니다.**

| 형식·필드 | 읽는 방법 |
|---|---|
| `.json` | `"필드": 값` 형식. 다음 명령에는 필드 이름이 아닌 **값만** 복사 |
| `configuration.index` | `configuration` 객체 안의 `index` 값 |
| `.jsonl` | 한 줄이 사례 하나. 6문항이면 6행과 행별 오류 확인 |
| `.html` | 브라우저로 열어 표·실패 사례 확인 |
| `true` / `false` / `null` | 참 / 거짓 / 값 없음. `null`은 0이나 성공이 아님 |
| `manifest.json` | 이번 실행의 모델·지침·데이터·설정. 답변 파일과 별개 |
| `result_directory` | 결과 폴더 경로. 그 폴더 안의 응답·평가·소유 기록 확인 |

### 이름과 경로를 옮길 때

| 값 | 구분 |
|---|---|
| `prepare-hosted --name hosted` | 접두사 뒤에 붙일 **짧은 이름** |
| 이후 `azd deploy`의 서비스 | 준비 명령이 출력한 **전체 이름** |
| `prompt-agent create --name` | 내 접두사를 포함한 **전체 에이전트 이름** |
| `--cwd` | 준비 폴더의 절대 경로. 패키지 폴더·`azure.yaml` 파일 아님 |
| `--version` | 해당 자원의 실제 반환 버전. 지침 `v2`나 다른 자원의 버전 아님 |

`--cwd`는 한 명령의 대상 폴더만 지정합니다. 터미널은 계속 실습 루트에 둡니다. [08장의 값 복사 표](08-hosted.md#3-기존-프로젝트에-연결하는-독립-폴더).

## 다음 날 재개하기

**같은 프로젝트는 설치·생성부터 반복하지 않습니다.** 이전 폴더와 설정·결과를 유지합니다.

### 1. 기존 실습 폴더 열기

편집기에서 기존 폴더를 열고 새 터미널을 만듭니다. README와 `scripts/`가 있는 폴더여야 합니다.

### 2. 내 OS의 가상 환경 활성화

**macOS / Linux**

```bash
source .venv/bin/activate
```

**Windows PowerShell**

```powershell
.\.venv\Scripts\Activate.ps1
```

PowerShell 활성화가 차단되면 정책을 낮추지 않습니다. 이후 `python`을 `.\.venv\Scripts\python.exe`로 바꿉니다.

### 3. 로컬 준비와 저장한 설정 확인

```bash
python scripts/workshop.py doctor
```

`result: PASS`를 확인합니다.

**00장의 configure를 마친 환경에서만**

```bash
python scripts/selfstudy.py values
```

프로젝트·접두사·모델이 이전 실습과 같아야 합니다. `먼저 Lab 00의 configure`가 나오면 [00장의 설정 단계](00-setup.md#8-실제-값으로-설정-자동-수집)부터 마칩니다.

`values`와 `status`는 **저장 파일만** 읽습니다. Azure 자원의 현재 존재·로그인 상태는 확인하지 않습니다.

### 4. 저장한 결과에서 이어가기

**새 Azure 요청을 보내기 전** 인증과 배포를 확인합니다.

```bash
python scripts/workshop.py doctor --cloud
```

이 검사는 모델을 호출하지 않습니다. 기대 구독·테넌트·Sol 배포와 `Succeeded`를 확인합니다. 로그인 만료라면 [00장의 로그인](00-setup.md#3-로그인과-이름-계획)을 수행합니다.

[저장 위치](#설정과-결과를-다시-찾는-곳)에서 마지막 결과를 읽고, 해당 장의 **완료 확인** 이후부터 이어갑니다. 파일 저장소의 만료·예약·세션 상태도 해당 서비스에서 확인합니다.

기존 답변만 읽을 때는 파일을 열면 됩니다. 로그인이나 모델 재호출이 필요하지 않습니다.

### 두 터미널을 사용하는 장

05·08·10장에서는 역할을 나눕니다.

| 터미널 | 역할 | 정상 상태 |
|---|---|---|
| A | 서버 실행 | 프롬프트 대신 서버 로그 표시 |
| B | 상태 확인·요청 | 명령이 끝나면 프롬프트 복귀 |

B도 같은 폴더에서 가상 환경을 활성화합니다. 완료·오류·중단 시 **터미널 A**에서 `Ctrl+C`를 눌러 내 서버를 종료합니다.

## 같은 이름으로 다시 실행해도 되나요?

| 상황 | 다음 행동 |
|---|---|
| 응답·label·패키지·폴더가 이미 있음 | 먼저 기존 결과 확인. 새 실행만 `candidate-2` 등 새 이름 사용 |
| 인덱싱·관리형 job이 진행 중 | 같은 ID·label로 상태 조회. 중복 생성 금지 |
| 모델·지침·코드·원문 변경 | 이전 결과 보존. 같은 조건의 새 전후 쌍으로 비교 |
| 비용·권한·지원에 막힘 | 원래 오류와 생성된 자원 확인. 반복 생성·권한 확대부터 하지 않음 |

## 매 장에서 확인할 네 가지

**대상 → 설정 → 실제 결과 → 중지할 자원**을 확인합니다. 명령 종료·답변 생성·품질 통과는 서로 다릅니다.

### 오류가 보이면 다음으로 가도 되나요?

| 결과 | 다음 행동 |
|---|---|
| `ERROR`, traceback, 인증/API 오류, 응답 누락 | 의존하는 다음 명령 중지 |
| 응답 6행·요청 오류 0, 업무 검사 일부 실패 | 실패를 읽고 지침 비교 가능. 낮은 점수 때문에 무작정 재수집하지 않음 |
| 서버 job 실행 중, 로컬 대기만 시간 초과 | 같은 ID·label로 조회 계속 |
| 최종 품질 실패·판정 불일치 | 인수·holdout 보류. 중지·비용 정리는 수행 |

## 막힌 단계가 있을 때

**그 기능에 의존하는 단계만** 멈춥니다.

| 막힌 기능 | 진행 가능한 범위 |
|---|---|
| 기본 Sol 배포·첫 호출 | Azure 실습 중지. 만든 자원은 15장에서 확인 |
| File Search·Code Interpreter | 기본 모델이 동작하면 로컬 MAF·함수·MCP·워크플로 진행 |
| Search | Search 의존 단계와 Toolbox/OpenAPI 중지. 07장의 local 평가는 가능 |
| Hybrid·IQ Chat만 미지원 | 원래 키워드 인덱스·IQ 결과는 별도 사용 가능 |
| 원격 Hosted | 08장의 로컬 준비가 되면 연결 실습 가능. 원격 결과는 미실행 |
| Memory·embedding | 준비된 A2A·Routine은 각각 진행 가능 |
| Optimizer | 후보가 없어도 준비된 Hosted `v1`/`v2` 비교 가능 |
| Hosted 보호 정책 | 별도 영어 대상·judge·로그가 있으면 13장 관리형 평가 확인 가능 |
| GitHub 권한 | 14장 생략 후 15장 진행 |

12장에서 local 경로를 선택해도 Search·IQ 성공으로 기록하지 않습니다. SDK 최종 평가와 Hosted 인수도 구분합니다.

다른 프로젝트로 전환할 때는 [새 폴더 준비](00-setup.md#새-프로젝트에서-이전-상태를-인수하지-않기)를 따릅니다. 과거 보고서와 다른 프로젝트의 성공은 본인의 결과가 아닙니다.

> [!WARNING]
> 중단 시 [15장의 중지 절차](15-capstone-cleanup.md#4-먼저-실행-중인-것을-멈추기)를 수행합니다. **Search·파일·볼륨·로그 비용은 실행 중지 뒤에도 남을 수 있습니다.**

## 파일 전달

개인 설정을 제외한 실습 ZIP을 만듭니다.

```bash
python scripts/package_workshop.py
```

코드·데이터·가이드·테스트가 포함되고 `.env`, `.selfstudy/`, 실행 결과, 가상 환경은 제외됩니다. 생성된 manifest를 확인합니다.

ZIP이 이미 있다면 덮어쓰지 않습니다. 새 배포본이 필요할 때만 `--output dist/workshop-new.zip`처럼 새 파일명을 사용합니다. 받은 사람은 [00장](00-setup.md)부터 시작합니다.
