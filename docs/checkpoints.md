# 막히지 않고 진행하는 방법

한 번에 한 단계만 진행합니다. **명령 입력 → 결과 확인 → 기록 → 다음** 순서를 유지하세요.

## 매 장에서 확인할 네 가지

- 내가 만들거나 바꾸는 대상이 무엇인가?
- 지금 사용하는 프로젝트·모델·버전이 맞는가?
- 실제로 확인한 결과는 무엇인가?
- 멈춘다면 무엇을 정리해야 하는가?

명령의 종료, 실제 응답, 품질 통과는 서로 다릅니다. 실패나 미지원 기능은 그대로 기록하고 [문제 해결](troubleshooting.md)의 해당 항목부터 확인합니다.

## 꼭 지킬 것

설정과 결과는 한 폴더에 유지합니다. 값을 잊었다면:

```bash
python scripts/selfstudy.py values
```

이미 만든 자원이나 파일을 다시 만들기 전에 기존 결과를 읽습니다. 다른 사람의 토큰·응답·계정을 사용하지 않습니다.

## 파일 전달

개인 설정 없이 실습 자료를 압축하려면:

```bash
python scripts/package_workshop.py
```

ZIP에는 코드·데이터·가이드·테스트가 함께 들어갑니다. `.env`, `.selfstudy`, 실행 결과와 가상 환경은 제외됩니다. 받은 사람은 압축을 풀고 [00](00-setup.md)부터 시작합니다.
