# 실습 결과를 복습하고 한 가지씩 비교하기

`outputs/`에 저장된 결과를 열어 복습합니다. 필요한 파일은 [설정과 결과를 다시 찾는 곳](checkpoints.md#설정과-결과를-다시-찾는-곳)에서 확인할 수 있습니다.

1. 실제 Sol 배포와 별칭, GPT-5.5 judge, API와 정확한 agent 버전을 확인합니다.
2. 답변을 합성 정책 원문·실제 도구 결과와 대조합니다.
3. 미실행·오류·누락·품질 실패를 구분하고 원시 결과를 보관합니다.
4. 다시 비교할 때는 새 label을 사용하고 지침 등 한 가지 조건만 바꿉니다. 저장된 manifest에서 언어·모델·원문·retrieval·judge 조건도 대조합니다.
5. holdout은 이미 본 질문을 새 시험으로 재사용하지 않습니다.
6. 예약과 불필요한 세션을 중지하고, 보존한 자산과 남는 비용을 포털에서 확인합니다.

다음 비교도 동봉한 합성 자료와 실습 기능 안에서 진행합니다. 모델이나 참여자를 늘리는 것만으로 개선이 입증되지는 않습니다.
