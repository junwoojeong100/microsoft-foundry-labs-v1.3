# 수업 다음에 무엇을 더 배울까요?

**7시간을 마친 뒤, 내 업무에 필요한 다음 문제 하나만 고릅니다.** v1.2의 기능은 v1.5의 [기능별 실습 카드](features/README.md)와 고정 원본 코드로 유지합니다. 기능이 제공되는 것과 본인이 실제로 구축·배포한 것은 구분합니다.

| 내 다음 문제 | 이어서 볼 것 | 추가로 고려할 책임 |
|---|---|---|
| 문서가 많고 갱신·문서별 권한이 중요하다 | Azure AI Search / Foundry IQ | 검색 품질, 사용자별 접근, 동기화, 비용 |
| 여러 시스템의 도구를 공유해야 한다 | Foundry Toolbox / MCP | 도구 서버 신뢰, 인증, 허용 범위, 데이터 전송 |
| 여러 단계의 작업을 코드로 제어해야 한다 | Microsoft Agent Framework | 워크플로 상태, 오류 복구, 사람 승인 |
| 이 Python 앱을 다른 사용자에게 제공해야 한다 | Hosted Agent 또는 적절한 앱 호스팅 | 사용자 인증, managed identity, 비밀 관리, 확장, 장애 대응 |
| 실제 승인·예약 도구를 붙여야 한다 | 도구 권한·human-in-the-loop 설계 | 실행 전 명시적 승인, 중복 방지, 감사, 취소/보상 |
| 지침을 바꿀 때마다 자동 검증하고 싶다 | 회귀 평가와 CI/CD | 데이터 분리, 평가 버전, 실패 시 차단, 비용 |
| 운영 중 품질 저하를 찾고 싶다 | 지속 평가와 모니터링 | 샘플링·보관·개인정보·경보·대응 담당자 |
| Teams에서 제공하고 싶다 | 에이전트 게시·채널 통합 | 테넌트 승인, 사용자 ID, 채널 정책 |

이번 수업은 **Prompt Agent + 로컬 앱**입니다. 본인의 전체 코드를 Foundry 런타임에 배포하는 **Hosted Agent**와 구분합니다.

권장 다음 순서: **작은 업무 하나 선택 → 승인된 데이터 확인 → 읽기 전용 도구부터 → 새 평가 문항 → 접근·비용·오류 통제 → 제한된 사용자에게 제공**.

실행 안내는 [전체 기능 대응표](feature-map.md), 공식 자료는 [출처 문서](sources.md), 개정 방향은 [v1.5 변경 지도](../v1.5-changes.md)에 있습니다. 기본과 호환 환경의 데이터·SDK·평가 결과를 섞지 마세요.
