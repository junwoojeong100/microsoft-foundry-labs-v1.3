# 업무로 가져가기 전에

자가 실습을 마쳤어도 생산 운영 승인은 별개입니다. [개인 워크북](../worksheets/workbook.md)의 업무 적용 카드로 다음을 정합니다.

1. 실제 문제와 측정할 업무 지표.
2. 승인된 원본 데이터·접근 권한·갱신 책임.
3. 읽기 전용 도구와 실제 쓰기/승인 도구의 분리.
4. 검증용 데이터·오류·업무 경계·회귀 기준.
5. 사용자 인증·관리 ID·네트워크·민감 로그 최소화.
6. 비용·장애·rollback·삭제 책임.

하나의 작은 업무부터 제한된 사용자에게 제공하고, 원문·실행·품질을 반복해서 확인합니다. 더 많은 모델이나 에이전트를 추가하는 것만으로 운영 문제가 해결되지는 않습니다.
