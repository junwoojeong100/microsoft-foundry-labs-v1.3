# 오프라인 fixture

[English](README.md) | **한국어**

`demo`는 미리 작성한 답변 여섯 개를 그대로 읽는 **검사기 연습**입니다.
Azure, Foundry, Agent Framework 또는 LLM을 실행한 결과가 아닙니다.
`v1`에서는 인용을 의도적으로 제거해 검사 실패를 관찰합니다.
이 차이는 모델이나 프롬프트의 실제 성능 개선을 입증하지 않습니다.

국문 fixture(`answers.json`)는 바뀌지 않으며, 영문은 별도로 고정한 fixture `en/answers.json`을 사용합니다.
[데이터 구분](../../docs/data-format.md)을 확인하세요.
